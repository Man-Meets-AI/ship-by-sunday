# Homepage Message Hierarchy Example

## Goal

Turn the product facts into a homepage narrative that matches the codebase-first product and the current public promise.

## Audience

Builders who can already prototype or get things working, but keep getting stuck before they ship a real v1.

## Core message ladder

- Brand signal: Ship by Sunday
- Promise: Ship a real, durable product by Sunday
- Mechanism: capture the product truth first, then compile Design, Marketing, Build, and Prompt Packs
- Proof angle: built by someone who ships, not theory from the sidelines
- Conversion angle: one payment, lifetime access, start the intake right after checkout

## Claims used

- evergreen approved claims only

## Claims withheld

- live founder metrics unless re-verified
- any guarantee wording beyond the current approved guarantee
- any implied promise that we ship the product for the buyer

# Plan Split Recommendation

## Slice 1: Workflow Bundle Scaffold

Create the `docs-spine-adoption` workflow bundle, manifest contract, phase runner skeleton, core schemas, proof artifact shape, CLI and daemon placeholders, approval packet constants, and minimal tests. Keep the first proof path small: resolve an approved packet, write `.sbs` facts/proof artifacts, and block safely when confirmation, lease, branch, or worktree rules fail.

## Slice 2: Scanner And Facts Model

Implement deterministic scanners for package manager, scripts, workspace topology, docs surfaces, agent instructions, nested instruction files, local skill folders, generated-output lanes, specs or product-spec lanes, CI/release surfaces, command proof mapping, route/package architecture signals, Semgrep rule execution, and bounded AST signals. Output normalized JSON facts and performance timings.

## Slice 3: Codex Synthesis Packets

Add bounded prompt packets and output schemas for `docs/index.md`, architecture, reliability, security, frontend/design, product sense, quality score, specs, references, generated docs, Program packet, first ExecPlan, prompt inventory, lane-local `AGENTS.md` files, skill-trigger manifest updates, and canonical instruction routing. Codex outputs drafts with claims, evidence refs, and blocked facts.

## Slice 4: Apply And Proof

Apply approved docs-spine files on a local branch. Validate frontmatter, links, Program packet shape, ExecPlan shape, prompt inventory, markdown metadata, skill-trigger resolution, docs-spine route checks, stale-path checks, and repo-native proof commands. Write local proof and sync-safe proof metadata plus a Worker and Ship by Sunday parity checklist.

## Slice 5: Arena CRM Pilot

Run the workflow against `~/Developer/arena-crm`. Preserve `.codex/AGENTS.md` as canonical, keep root `AGENTS.md` as a shim, use `bun run gate` as the broad proof command, install the docs spine, record proof, and capture any blocked facts for later loops.

## Deferred Or Separate Work

A Go scanner engine, hosted execution, package script mutation, CI workflow mutation, PR creation, raw-source sharing, and quality-score table population are not part of the first scaffold.

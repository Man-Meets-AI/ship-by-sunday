# 1. Core Visual Philosophy

Ship by Sunday is not presented as:

```id="b3gpc3"
an online course
```

It is presented as:

```id="v8f2ij"
a system for shipping software
```

Visual tone:

```id="vztqys"
precise
minimal
builder-focused
technical
```

Reference brands:

• Linear
• Vercel
• Stripe docs
• Apple developer tools

Avoid:

```id="j8qfja"
gamer aesthetics
startup bro imagery
stock photos
marketing fluff graphics
```

# 2. Builder Classes System

The **Builder Classes** represent the idea that AI allows one person to perform the work of an entire startup team.

The four classes correspond to the four blocks.

```id="gj8a1d"
STRATEGIST
ARCHITECT
ENGINEER
LAUNCHER
```

Which map to:

```id="d3n1bl"
CEO
DESIGN
BUILD
SHIP
```

These classes become a **visual storytelling system** used in marketing.

# 4. Class Graphics

Each class should have an **individual graphic**.

These graphics appear in:

• sales page sections
• social posts
• lesson introductions

---

# Class 1 — Strategist

Represents the **CEO block**.

Purpose:

Identify the right problem to solve.

Visual cues:

• builder observing the market
• laptop or tablet
• diagrams or maps

Symbolic artifacts:

• network nodes
• opportunity map

Graphic caption:

```id="f3aqeo"
STRATEGIST
Find the right problem.
```

---

# Class 2 — Architect

Represents the **Design block**.

Purpose:

Turn the idea into product structure.

Visual cues:

• wireframes
• UI panels
• stylus / tablet

Symbolic artifacts:

• layout grids
• interface blocks

Graphic caption:

```id="3j4bpc"
ARCHITECT
Shape the product.
```

---

# Class 3 — Engineer

Represents the **Build block**.

Purpose:

Construct the software.

Visual cues:

• laptop with code
• system diagrams
• assembling modules

Symbolic artifacts:

• stacked blocks
• system nodes

Graphic caption:

```id="g7g2l1"
ENGINEER
Turn ideas into software.
```

---

# Class 4 — Launcher

Represents the **Ship block**.

Purpose:

Deploy and reach users.

Visual cues:

• analytics screen
• phone notifications
• distribution networks

Symbolic artifacts:

• launch arrow
• spreading nodes

Graphic caption:

```id="a3i7ra"
LAUNCHER
Get it into the world.
```

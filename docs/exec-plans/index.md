# ExecPlans

`docs/exec-plans/` is the canonical ExecPlan surface for this repository.

Use [PLANS.md](PLANS.md) as the contract for authoring, revising, linting, and executing ExecPlans. Keep unfinished work under `docs/exec-plans/active/` and move finished plans into `docs/exec-plans/completed/` once `status: complete` is true.

Use [tech-debt-tracker.md](tech-debt-tracker.md) for follow-up planning debt that does not belong inside a single initiative plan.

# Ship by Sunday Review Matrix

Use this file to decide what can be drafted freely, what must be reviewed, and what must never auto-publish.

| Workflow | Can draft without approval | Human review required before use | Must never auto-publish |
|---|---|---|---|
| Homepage message hierarchy | Yes | Yes | Yes |
| Launch email outline | Yes | Yes | Yes |
| Social variants | Yes | Yes | Yes |
| Competitor or market research brief | Yes | Yes if used for public claims | Yes |
| Internal review brief | Yes | No if it stays internal | Yes |
| Claim summary from stable codebase facts | Yes | Yes before public use | Yes |
| Any output using current facts | Yes after verification | Yes | Yes |
| Anything with pricing, guarantee, or founder proof | No | Yes | Yes |

## Default rule

No external-facing content from this pack should publish automatically.

## Extra review triggers

Require explicit review when the output:

- includes pricing or guarantee language
- uses quantified proof or founder metrics
- adds a new positioning angle
- uses current market or competitor facts
- introduces a new channel not already inside `channel_scope`

# Marketing Page Rules

## Purpose

Use this when the task is a marketing surface that may extend beyond the hero but still needs strong brand presence.

## Non-negotiables

- Keep the narrative clear: explain, prove, deepen, convert.
- Give each section one job.
- Keep supporting copy short enough to scan in seconds.
- Remove repeated mood statements and redundant section intros.
- Avoid decorative cards unless they clearly improve comprehension.

## Strong defaults

- Use one accent color unless the product already has a mature multi-accent system.
- Use one primary CTA above the fold when conversion matters.
- Prefer real product context over generic marketing copy.
- Use imagery or proof surfaces only when they materially strengthen the story.

## Good review questions

- Does each section advance the story?
- Is there any section that exists only because marketing pages often have that section?
- Can the page still work if I remove one decorative surface?

# OpenAI Long-Horizon Build Baseline

This folder is the neutral baseline for long-horizon Codex work.

It is the vanilla template layer for substantial implementation tasks that need a spec, milestone plan, execution runbook, and live documentation log.

## What is in here

- `AGENTS.md` - the baseline operating contract for long-horizon runs.
- `CHECKLIST.md` - the baseline readiness and execution checklist.
- `docs/prompt.md` - the canonical task spec template.
- `docs/plans.md` - the milestone plan template.
- `docs/implement.md` - the execution runbook template.
- `docs/documentation.md` - the live status and audit log template.

## How to use it

1. Use this folder as the vanilla starting point.
2. Layer product-specific constraints on top in a custom pack.
3. For Ship by Sunday repo work, use `docs/ship-by-sunday/build-pack/` as the live custom layer.

## Source policy

These files are the baseline source set for long-horizon execution in this repo. Re-verify them whenever the official OpenAI long-horizon guidance changes materially.

## 1) Core model: how OpenAI frames marketing work

OpenAI’s “Identifying and scaling AI use cases” guide says most work falls into six primitives:

- Content creation
- Research
- Coding
- Data analysis
- Ideation and strategy
- Automation

OpenAI also gives a direct example of a **marketing workflow** that spans those primitives:

- Deep research to understand market trends and opportunities
- Data analysis to size audience and opportunity
- Brainstorm strategy and develop the brief
- Content creation to craft key messages and copy
- Automate localization and channel optimization

### Checklist

- [ ] Teach the six primitives to the marketing team.
- [ ] Map every existing marketing workflow step to one or more primitives.
- [ ] Inventory repetitive low-value tasks in marketing.
- [ ] Inventory skill bottlenecks in marketing.
- [ ] Inventory ambiguity-heavy tasks where teams struggle to get started.
- [ ] Create a single backlog of candidate use cases.
- [ ] Score each use case by impact vs effort.
- [ ] Revisit scoring quarterly as capabilities improve.
- [ ] Explicitly prioritize quick wins that improve whole-team momentum.

**References:**  
Identifying and scaling AI use cases; Estée Lauder GPT Lab; Building OpenAI with OpenAI

## 3) Capability inventory: OpenAI features marketers should know how to use

This is the operational layer: not just “what use cases exist,” but what capabilities you need in the repo so those use cases are actually repeatable.

### 3.1 Deep research

- [ ] Use deep research for multi-step research that needs synthesis and citations.
- [ ] Start with a specific question and desired output format.
- [ ] Review and adjust the research plan before it runs.
- [ ] Specify which sources are in-bounds: web, uploaded files, connected apps, or specific websites only.
- [ ] Use deep research for competitor teardowns, market scans, vendor evaluation, and user research synthesis.
- [ ] Require evidence separation: claims vs proof.
- [ ] Save the research output into the project or repo, not just the chat.
- [ ] Record assumptions, cutoff date, and source boundaries in the output.

**References:**  
Deep research; Deep research in ChatGPT

### 3.2 Projects

- [ ] Create one Project per durable workstream: brand, launch, campaign, region, audience, product line, research stream, etc.
- [ ] Put relevant files, examples, and instructions in the Project.
- [ ] Use project-wide instructions to enforce tone, formatting, naming, and review norms.
- [ ] Keep a shared Project for collaborative campaign work.
- [ ] Use Projects to centralize the working context instead of repeatedly pasting instructions.
- [ ] Treat Projects as your default workspace for campaigns that span multiple chats.
- [ ] Document what belongs in Project memory vs what must be provided fresh each run.

**References:**  
Projects; Projects in ChatGPT; More ways to work with your team and tools in ChatGPT

### 3.3 Canvas

- [ ] Use Canvas for drafts that need revision, editing, restructuring, or collaborative commenting.
- [ ] Ask Canvas to compress, expand, reframe, or rewrite specific sections.
- [ ] Highlight only the section you want changed when the brief should stay stable.
- [ ] Use version restore during iterative reviews.
- [ ] Keep long-form copy refinement in Canvas instead of pure chat.

**References:**  
Introducing Canvas; Canvas feature in ChatGPT

### 3.4 Data analysis

- [ ] Upload real spreadsheets instead of manually summarizing them.
- [ ] Ask for the model to describe the dataset before concluding.
- [ ] Request the exact table or chart type needed.
- [ ] Use interactive table selection to ask targeted follow-ups.
- [ ] Standardize recurring KPI packs and chart requests.
- [ ] Keep stable metric definitions in knowledge files; bring fresh data in each run.

**References:**  
Data analysis with ChatGPT; Extracting insights with ChatGPT Data Analysis; Four GPT templates for small businesses

### 3.5 Images

- [ ] Use image generation for moodboards, concepting, campaign imagery, and draft visual exploration.
- [ ] Use iterative prompting instead of trying to perfect the image in one shot.
- [ ] Edit only the needed area when refining an existing image.
- [ ] Explicitly state typography, background, composition, or aspect-ratio requirements.
- [ ] Keep brand review, legal review, and accessibility review in the loop.

**References:**  
Creating images; Creating images in ChatGPT; Editing images with ChatGPT Images

### 3.6 Voice and Record

- [ ] Use voice mode for spoken brainstorming and creative unblock.
- [ ] Use Record for brainstorms, postmortems, customer interviews, and planning sessions.
- [ ] Convert recorded conversations into briefs, plans, summaries, and action lists.
- [ ] Confirm recording consent and applicable laws before use.

**References:**  
Using voice; Voice mode FAQ; ChatGPT Record

### 3.7 Scheduled tasks and agent flows

- [ ] Use scheduled tasks for lightweight recurring outputs.
- [ ] Use ChatGPT agent when the workflow is truly multi-step and benefits from tool use.
- [ ] Schedule completed agent tasks to recur only after you trust the workflow.
- [ ] Keep a list of what requires manual review before publication or send.
- [ ] Avoid over-automating high-risk outputs too early.

**References:**  
Scheduled tasks in ChatGPT; Introducing ChatGPT agent; ChatGPT agent

### 3.8 Connectors and company knowledge

- [ ] Use connected apps for internal docs, files, analytics exports, and knowledge retrieval.
- [ ] Use company knowledge when you want organization-specific answers with citations across connected sources.
- [ ] Connect SharePoint or Google Drive if your marketing knowledge base lives there.
- [ ] Decide which repositories count as approved knowledge.
- [ ] Keep permissions and ownership clear.
- [ ] Require citations or direct references when internal knowledge is used in research or drafting.
- [ ] Be aware that connectors and agent workflows can be vulnerable to bad source material or prompt injection; keep review in the loop.

**References:**  
Connectors in ChatGPT; Introducing company knowledge; Company knowledge in ChatGPT; Add files from connected apps in ChatGPT; ChatGPT agent

- [ ] Blueprint repeatable workflows as GPTs, skills, or documented agent specs.
- [ ] Give each GPT a clear name, description, and conversation starters.
- [ ] Put rules in instructions; put stable source material in Knowledge.
- [ ] Prefer text-heavy, well-structured reference files for Knowledge.
- [ ] Tell the GPT when to quote or cite source material.
- [ ] Preview-test with real prompts before rollout.
- [ ] Tighten instructions and examples before adding more tools.
- [ ] Reuse OpenAI skill patterns such as brand-voice polish and multi-channel performance digest.
- [ ] Keep fresh campaign variables out of Knowledge and in the current run.

## 4) Repo checklist: documented best practices for building and prompting marketing workflows

This section translates the guidance into rules your repo can enforce.

### 4.1 Prompting and instruction quality

- [ ] Be clear and specific about task, audience, channel, format, and constraints.
- [ ] Iterate prompts instead of expecting the first prompt to be production-ready.
- [ ] Use the latest, most capable model available for complex work.
- [ ] Separate stable behavior from one-off request details.
- [ ] For customer-facing writing, separate persistent persona/brand guidance from per-output formatting controls.
- [ ] Set hard length limits when output length matters.
- [ ] Specify emotional register, channel, and formatting rules when relevant.
- [ ] Explicitly ban unwanted formatting or behaviors.
- [ ] Give positive, concrete instructions instead of vague prohibitions.
- [ ] Include examples when possible.
- [ ] Organize long instructions with headings and step order.

**References:**  
Prompt engineering best practices for ChatGPT; Best practices for prompt engineering with the OpenAI API; Prompt guidance; Creating and editing GPTs

### 4.2 Brand voice and style consistency

- [ ] Put brand voice guidance in project instructions, GPT instructions, or a dedicated knowledge file.
- [ ] Upload examples of strong past assets to teach style.
- [ ] Define do-not-say rules and lexical preferences.
- [ ] Require the model to mirror tone without copying reference text.
- [ ] Keep one canonical source for approved voice guidance.
- [ ] Create a dedicated “brand voice polish” workflow for post-draft cleanup.

**References:**  
More ways to work with your team and tools in ChatGPT; Customizing ChatGPT; Skills; Four GPT templates for small businesses

### 4.3 Stable knowledge vs fresh inputs

- [ ] Put stable references in Knowledge: style guides, brand rules, product/service facts that do not change often, approved FAQs, evergreen positioning.
- [ ] Bring live campaign details in the run itself: dates, offers, pricing, launch timing, current metrics, current competitors, live event info.
- [ ] Do not treat stale knowledge as current truth.
- [ ] If the answer depends on current facts, use web search, deep research, or manual verification.
- [ ] Tell the system to ask before guessing when required inputs are missing.

**References:**  
Creating and editing GPTs; Deep research in ChatGPT; Four GPT templates for small businesses

### 4.4 Human review and approval

- [ ] End critical workflows with a human-check step.
- [ ] Require review before publishing externally.
- [ ] Require review before using performance claims or competitor comparisons.
- [ ] Require review before using legal, financial, regulatory, or medical claims.
- [ ] Keep expert review loops for high-value workflows.
- [ ] Sample outputs weekly and tighten instructions based on failure modes.

**References:**  
Responsible use of ChatGPT at work; OpenAI GTM Assistant; Introducing ChatGPT agent; Four GPT templates for small businesses

### 4.5 Safety, privacy, and policy

- [ ] Follow workplace policies and OpenAI policies.
- [ ] Do not upload sensitive personal data unless there is a real need and proper handling.
- [ ] Get consent before recording conversations where required.
- [ ] Avoid using generated content as final truth in regulated or high-risk contexts without review.
- [ ] Keep track of what data sources are approved for marketing use.
- [ ] Treat connectors, external content, and autonomous browsing as possible prompt-injection surfaces.
- [ ] Prefer least-privilege access for apps and actions.
- [ ] Log what the workflow can publish, send, or change.

**References:**  
Responsible use of ChatGPT at work; ChatGPT Record; ChatGPT agent; Connectors in ChatGPT

## 5) Team operating checklist: how to scale this beyond one marketer

### 5.1 Use-case collection and prioritization

- [ ] Run workshops, hackathons, or use-case sprints.
- [ ] Ask every team member for low-value tasks, blockers, and skill bottlenecks.
- [ ] Create one shared spreadsheet, backlog, or channel for ideas.
- [ ] Score each use case on value and effort.
- [ ] Start with quick wins that can scale across a team.
- [ ] Reassess old “too hard” ideas each quarter.

**References:**  
Identifying and scaling AI use cases; HYGH; Estée Lauder GPT Lab

### 5.2 Collaboration and knowledge sharing

- [ ] Use shared Projects instead of private one-off chats for team workflows.
- [ ] Share useful GPTs, project links, and documented prompts.
- [ ] Hold recurring “show your workflow” sessions.
- [ ] Turn ad hoc prompts into reusable assets only after they prove value.
- [ ] Let expert users define what “good” looks like for others.
- [ ] Capture learnings from failed runs, not just successful ones.

**References:**  
More ways to work with your team and tools in ChatGPT; HYGH; OpenAI GTM Assistant; Building OpenAI with OpenAI

### 5.3 Measurement and feedback

- [ ] Define success metrics before rollout: speed, quality, volume, conversion, cost, cycle time, consistency, error rate, adoption.
- [ ] Benchmark the manual baseline.
- [ ] Track savings or output improvements by workflow.
- [ ] Collect user feedback and failure examples.
- [ ] Sample outputs regularly for quality review.
- [ ] Retire workflows that do not beat the manual baseline.

**References:**  
Identifying and scaling AI use cases; OpenAI GTM Assistant; Estée Lauder GPT Lab; State of enterprise AI 2025 report

# Clerk + Convex Auth

This is the most important setup page in the starter.

If Clerk and Convex do not agree on the `convex` JWT template and issuer, the app can sign users in while protected server-side reads still fail.

## Required env values

Make sure `.env.local` has these values:

```bash
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
CLERK_FRONTEND_API_URL=
NEXT_PUBLIC_CONVEX_URL=
```

`NEXT_PUBLIC_CONVEX_URL` usually comes from the Convex tooling once you run the local or hosted dev setup.

## Clerk setup

1. Create a Clerk app.
2. Copy `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`, and `CLERK_FRONTEND_API_URL`.
3. Keep the Clerk frontend API domain consistent everywhere you wire auth.

## The `convex` template is not optional

Inside Clerk:

1. Open your app.
2. Go to `JWT Templates`.
3. Create or confirm a template named `convex`.
4. Use `convex` as the application ID.
5. Make sure the issuer/domain matches your Clerk frontend API URL.

This starter is hard-wired to that identifier.

## Convex setup

Connect the repo to Convex with the repo-local command:

```bash
bun run dev:convex
```

That local flow should give you the `NEXT_PUBLIC_CONVEX_URL` value the app expects. If you intentionally switch to a hosted Convex dev flow later, keep the Clerk app, frontend API domain, and token-template assumptions aligned.

## What success looks like

You are correctly wired when:

- sign-in works
- protected routes can read server-side state
- `/access-required` can tell the difference between signed-out and signed-in users
- product-access checks do not fail with a token or issuer mismatch

## If this breaks

Check these in order:

1. the Clerk JWT template is named exactly `convex`
2. the issuer/domain in Clerk matches the same Clerk frontend API domain used by the app
3. the Convex env is not still pointed at an old or different Clerk instance
4. you restarted the app after changing auth env values

If checkout succeeds but access still fails, go straight to [Troubleshooting Stripe and Convex](/docs/troubleshooting/stripe-convex).

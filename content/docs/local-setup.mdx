# Local Setup

The local setup order matters more than most people expect.

Use this order:

1. Clerk
2. Convex
3. Stripe

If you skip the order, the app can look close to working while the paid-access handoff is still broken.

## Before you start

Have these ready:

- Node.js LTS
- `bun`
- a Clerk account
- a Convex account
- a Stripe account
- a Vercel account for deployment later
- a GitHub account if you plan to use the Build starter-template path later

## First local boot

Install the repo and copy the local env template:

```bash
bun install
cp .env.local.example .env.local
```

Then follow the provider wiring pages in this order:

- [Clerk + Convex Auth](/docs/clerk-convex-auth)
- [Stripe Checkout + Webhook](/docs/stripe-checkout-webhook)

Once those values are in place, start the full local stack:

```bash
bun run dev
```

Open `http://localhost:3000`.

## Which local command to use

Use these commands intentionally:

```bash
bun run dev
bun run dev:web
bun run dev:convex
```

- `bun run dev` starts the app and local Convex together
- `bun run dev:web` starts only the Next.js side
- `bun run dev:convex` starts only the local Convex side

If you intentionally want a hosted Convex dev deployment, use `bunx convex dev` manually and treat that as a different workflow.

## The fastest way to confirm the setup

Once the app boots, validate the basics:

```bash
bun run build
bun run stripe:local:doctor
```

Then finish the real flow with [Local QA](/docs/local-qa).

## What success looks like

You are ready for real customization when:

- the marketing page loads locally
- `/docs` loads locally
- you can reach sign-in
- Convex connects cleanly
- Stripe listener setup does not report account or secret drift
- the app can complete the local QA flow without fake shortcuts

## If this breaks

- Auth issues: go to [Clerk + Convex Auth](/docs/clerk-convex-auth)
- Checkout/access issues: go to [Stripe Checkout + Webhook](/docs/stripe-checkout-webhook)
- Access still does not appear: go to [Troubleshooting Access](/docs/troubleshooting/access)

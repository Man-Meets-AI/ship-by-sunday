# Configure the Homepage

The public homepage at `/` is now the Man Meets AI brand page. It is not the Starter sales page, not the Workers sales page, and not a checkout-first page.

## Current public IA

- `/`: Man Meets AI brand, media, founder, and routing page
- `/starter`: public Starter offer page
- `/workers`: public Workers offer page
- `/blog`: public editorial index and posts
- `/docs`: direct-link docs surface; do not promote it in primary public navigation

## Files to read first

When you change the public homepage or public marketing navigation, inspect these files:

1. `app/page.tsx`
2. `app/starter/page.tsx`
3. `app/workers/page.tsx`
4. `app/_components/public-site/public-site-header.tsx`
5. `config/product.ts`
6. `app/robots.ts`
7. `app/sitemap.ts`
8. `tests/unit/public-metadata-routes.test.ts`

The old generated-codebase homepage system under `app/_components/home-page/` still exists for compatibility and tests, but it is no longer the public `/` route contract.

## Rules

- Keep `/` informational. It should route visitors by intent: “I have an idea” goes to `/starter`; “I have a codebase” goes to `/workers`.
- Do not put docs, tutorials, or generated-codebase links in the primary public nav.
- Put checkout buttons on `/starter` and `/workers`, not on the Man Meets AI index.
- Starter checkout must use offer id `starter` and route successful buyers to `/starter/home`.
- Workers checkout must use offer id `workers` and route successful buyers to `/workers/setup`.
- Keep `/workers` public. Only Worker operational routes such as `/workers/setup`, `/workers/doctor-pass`, `/workers/findings`, `/workers/loops`, `/workers/runs`, and `/workers/privacy` are protected.

## Validation

For public route changes, run:

```bash
bun run --cwd apps/web test:unit -- tests/unit/public-metadata-routes.test.ts tests/unit/proxy-protected-routes.test.ts
```

For checkout CTA changes, also run:

```bash
bun run --cwd apps/web test:unit -- tests/unit/checkout-session-params.test.ts tests/unit/checkout-session.test.ts tests/unit/stripe-line-item.test.ts
```

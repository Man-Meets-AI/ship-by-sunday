# Commands

## Daily development

```bash
bun install
bun run dev
bun run dev:full
bun run dev:core
bun run dev:web
bun run dev:convex
bun run dev:stripe
bun run auth:dev:doctor
```

Run `bun run dev:convex` first on a new machine or whenever you need to switch hosted Convex dev deployments.

## Verification

```bash
bun run format
bun run lint
bun run typecheck
bun run test
bun run test:contracts
bun run build
bun run test:e2e
```

`bun run test:e2e` is the deterministic Playwright smoke lane. It uses the local production build by default. Deployment smoke reuses the same command against the deployed URL by setting `PLAYWRIGHT_BASE_URL`, `PLAYWRIGHT_USE_LOCAL_SERVER=0`, and `PLAYWRIGHT_CHECKOUT_SMOKE=1`.

## Ship by Sunday CLI

Use the repository-local launcher from the repo root with either `bun run sbs` or `./bin/sbs`. For the longer operating guide, read [Ship by Sunday CLI](/docs/ship-by-sunday-cli).

```bash
bun run sbs --help
bun run sbs --version
bun run sbs init --fixture complete --json
bun run sbs review --stage build-plan --missing-only --json
bun run sbs generate --out ./tmp/sbs-cli-repo --json
./bin/sbs completion zsh
```

## Stripe and auth helpers

```bash
bun run stripe:create-product
bun run stripe:listen:dev
bun run stripe:webhook:sync -- --secret whsec_...
bun run stripe:dev:doctor

bun run clerk:test-user:check
bun run clerk:test-user:create
bun run clerk:test-user:check:entitled
bun run clerk:test-user:create:entitled
bun run clerk:test-user:prepare:entitled
```

`bun run stripe:dev:doctor` is now just a local guardrail for the pinned Stripe CLI project. Checkout verification lives in the ordinary integration tests, Convex contract tests, and deployment smoke workflow.

# Local QA

Use this page as the main local verification runbook for the starter.

## Fast checks

```bash
bun run format
bun run lint
bun run typecheck
bun run test
bun run test:contracts
bun run build
bun run test:e2e
```

The local browser lane is now just `bun run test:e2e`. It builds the app and runs the deterministic public Playwright smoke suite.

## Clerk helper accounts

Use these only when you need manual local auth debugging:

```bash
bun run clerk:test-user:check
bun run clerk:test-user:create
bun run clerk:test-user:check:entitled
bun run clerk:test-user:create:entitled
bun run clerk:test-user:prepare:entitled
```

The account definitions now live directly in `apps/web/scripts/data/clerk-test-accounts.json`. They are app-local runtime fixtures now, not a separate repo-level system.

## Checkout and entitlement proof

The normal local proof no longer uses a billing pack, persona bootstrap, or authenticated sandbox Playwright lane.

Instead:

- `/api/stripe/checkout` is protected by integration tests.
- pending checkout claims and access grants are protected by offline Convex contract tests.
- deployment smoke can hit the real deployed checkout-session creation path when the environment is ready.

For local Stripe debugging, keep these helpers:

```bash
bun run dev:stripe
bun run stripe:dev:doctor
```

Use them when webhook forwarding itself is the thing you are diagnosing, not as part of the normal CI path.
